# What their names mean: the top four rosters

Reference for fact-checking, not script copy. Meanings come from the sources the classification used: Wiktionary, the web-research files in `data/interim/web_etymology_*.json` (mostly the Dictionary of American Family Names as reproduced online), and David's overrides in `data/overrides.csv`. "Evidence" is how solid the meaning is:
- **strong:** a dictionary states it plainly.
- **moderate:** one source, or a closely related spelling.
- **weak:** an inference or a popular explanation.

**⚑** marks a player whose source points to a different team than the one he plays for (see the end of this file).

Plain-English gloss of each type (Wikipedia's categories, for the GitHub write-up):
- **Toponymic:** named for a place. Where the family lived (a hill, a stream, a valley) or the town they came from.
- **Cognominal:** named for a nickname describing the first bearer: looks, personality, where they were from as a people, or acting like a king.
- **Patronymic:** named after a parent, almost always the father ("son of…"). It includes a few matronymics (named after the mother).
- **Occupational:** named for the job.

## ⚑ Source points to a different team

These are left as classified (David, 2026-10-11: no more classifications). `scripts/scenarios.py` shows what each move would do:
- **Tarik Skubal** (Occupational): the main source calls it a nickname ("plucked"), which is Cognominal. **On its own this would make Cognominal champion**, 68.13 to 67.85.
- **Ezequiel Duran** (Cognominal): from the first name Durand, so Patronymic. Moving him drops Cognominal to 65.80. Toponymic would still win.
- **Henry Bolte** (Cognominal): from the first name Baldo, so Patronymic. Cognominal drops to 67.16. Toponymic would still win.
- **Parker Messick** (Toponymic): one "possibly". As unknown, Cognominal wins, 67.79 to 65.87.
- All four moves together: Patronymic wins, 66.27.
